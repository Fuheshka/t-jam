# Т—ДЖЕМ

Геймджем на час для абитуриентов Т—Университета (ИСТ ДГТУ): команды за 30 минут придумывают концепцию игры на тему из направлений института и защищают её.

Сайт: https://fuheshka.github.io/t-jam/

| Файл | Что это |
|---|---|
| `index.html` | Стартовая страница со ссылками |
| `slides.html` | Презентация с анимациями (← → листать, F — полный экран, N — заметки ведущего) |
| `hat.html` | Шляпа: случайная тема и ограничение для каждой команды, без повторов |
| `timer.html` | Таймер: 30 минут по фазам и режим защиты по 5 минут |
| `print/cards.pdf` | Карточки тем и ограничений для печати (A4, 4 на лист) |
| `print/cards.html` | Исходник карточек |
| `print/jury.pdf` | Бланк жюри со шкалой оценки (A4, по листу на человека) |

Презентация живёт в Claude: экспорт в PPTX/PDF через Share → Export, файлы можно положить в `slides/`.

## Как провести

1. **Установка, 5–10 мин.** Открыть `slides.html`, нажать F. Презентация: что такое геймджем, роли, что на листе А3, критерии.
2. **Работа, 30 мин.** Открыть `timer.html`, нажать F (полный экран), «Старт».
   - 0–5: роли (геймдизайнер, сценарист, художник, продюсер)
   - 5–15: концепция. Темы тянем в `hat.html` в начале
   - 15: таймер напомнит — тянем ограничение в шляпе
   - 15–25: core loop, лого, обложка
   - 25–30: готовим выступление
3. **Защита, ~25 мин.** По 5 минут на команду: 3 на выступление, 2 на вопросы. В таймере режим «Защита · 5 мин», «Следующая команда» переключает и запускает заново. Жюри заполняет `print/jury.pdf` (по листу на человека).

Оценка: 4 критерия по 0–5 (геймплей, раскрытие темы, аудитория, защита) + 2 за обыгранное ограничение. Приз зрителей: после всех защит каждая команда вслух называет один чужой проект, который понравился больше всего (за себя нельзя). Больше голосов — приз, при ничьей решает жюри.

Нужно: экран, 4–6 листов А3, фломастеры, ручки, стикеры.

## Перед стартом

- В шляпе нажать «Сбросить всё», в таймере «Сначала» — состояние хранится в браузере и переживает перезагрузку.
- Звук таймера включается после первого нажатия «Старт».
- Без интернета шрифт Jost заменится на Arial, остальное работает. Можно открыть файлы прямо с диска.

## Как поменять

- **Темы и ограничения:** `hat.html`, объект `KINDS` в начале скрипта.
- **Фазы, подсказки, длительность:** `timer.html`, объект `MODES` в начале скрипта.
- **Карточки для печати:** правим `print/cards.html`, потом в Chrome «Печать → Сохранить как PDF» (A4, альбомная, без полей).
